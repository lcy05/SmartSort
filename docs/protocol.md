# 设备通信协议

本文描述应用与设备固件之间的应用层协议，是客户端实现的依据。协议由固件侧定义，客户端不得改变报文语义。

## 1. 传输层

| 项目 | 取值 |
| --- | --- |
| 网络形态 | 设备工作在 SoftAP 模式，手机作为 STA 接入 |
| 默认热点 | SSID `ESP25`，密码 `12345678` |
| 设备地址 | `192.168.4.1` |
| 端口 | `8080`（TCP） |
| 编码 | UTF-8 纯文本 JSON |
| 分帧 | 无换行、无长度前缀、无结束符 |

固件仅维护一条链路（内部 link 0），因此客户端保持单条长连接，不并发建立第二条连接。

## 2. 上行状态帧

设备按 500 ms 的周期主动推送状态帧，格式如下：

```json
{"tongk":1,"tongy":0,"tongq":1,"rubbish":0}
```

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `tongk` | 0 / 1 | 可回收物桶：`1` 未满可投放，`0` 已满 |
| `tongy` | 0 / 1 | 有害垃圾桶：`1` 未满可投放，`0` 已满 |
| `tongq` | 0 / 1 | 其他垃圾桶：`1` 未满可投放，`0` 已满 |
| `rubbish` | 0 | 固件保留字段，恒为 `0`，无业务含义 |

### 2.1 切帧规则

一次 `read` 可能返回多帧拼接内容，也可能返回半帧。客户端按花括号配对切分：

- 丢弃开始帧之前的噪声字符；
- 遇 `{` 记深度加一，遇 `}` 记深度减一，深度归零即得完整帧；
- 连接中断时未闭合的残片直接丢弃，不参与解析。

不含 `tongk` / `tongy` / `tongq` 任一字段的帧视为非状态帧（例如固件回显），忽略。

## 3. 下行指令

| 动作 | 报文 |
| --- | --- |
| 切换手动模式 | `{"mode": 0}` |
| 单桶开盖 | `{"mode": 0, "gaik": 1}` |
| 单桶关盖 | `{"mode": 0, "gaik": 0}` |
| 三桶全开 | `{"mode": 0, "gaik": 1, "gaiy": 1, "gaiq": 1}` |
| 三桶全关 | `{"mode": 0, "gaik": 0, "gaiy": 0, "gaiq": 0}` |

桶位与键名的对应关系与固件一致：`gaik` 对应可回收物，`gaiy` 对应有害垃圾，`gaiq` 对应其他垃圾。

### 3.1 分隔符约束

固件解析数值时按 `p += strlen(key) + 3` 的固定偏移定位起始字符，即**冒号后必须恰好一个空格**。

| 报文 | 结果 |
| --- | --- |
| `{"mode": 0}` | 正确，`mode` 取值为 `0` |
| `{"mode":0}` | 偏移错位，取到错误字符，指令失效或被误解析 |

该约束对所有数值字段成立。客户端由统一的指令构造函数生成报文，不手写字符串。

### 3.2 模式约束

固件启动时内部模式为自动（`s_mode = 1`），此状态下远程开合盖指令被忽略。因此连接建立后必须立即下发 `{"mode": 0}`，此后每条指令都携带 `mode` 字段，避免设备复位后再次进入自动模式而指令静默失效。

## 4. 在线判定

固件不回报连接状态，也不发送心跳或保活报文。客户端采用双重条件判定在线：

1. TCP 连接已建立；
2. 最近 1.5 秒内收到过状态帧（`soTimeout = 1500`）。

读取超时即视为掉线，关闭连接并进入重连流程。由于状态帧周期为 500 ms，1.5 秒约为三个周期，可容忍偶发丢帧而不误判。

## 5. 重连策略

| 项目 | 取值 |
| --- | --- |
| 触发条件 | 连接失败、读取超时、对端关闭 |
| 退避序列 | 2 s → 4 s → 8 s，此后固定 8 s |
| 重试上限 | 无，持续重试直至用户退出应用 |
| 复位条件 | 任意一次连接成功后退避计数归零 |

连接超时为 3 秒。重连成功后重新执行模式切换。

## 6. 无回执项

以下行为固件不提供确认，客户端以本地状态呈现，界面文案不使用「已开盖」等确定性表述：

| 项目 | 客户端处理 |
| --- | --- |
| 实际盖位 | 不回报。依据已下发指令推断，界面显示「开盖中 / 已关闭」 |
| 满桶拒开 | 不返回失败。依据状态帧提前禁用开盖并提示 |
| 指令送达 | 无 ACK。写入成功即视为已下发 |

## 7. 典型时序

```text
客户端 → 设备   TCP 连接建立
客户端 → 设备   {"mode": 0}
设备   → 客户端 {"tongk":1,"tongy":0,"tongq":1,"rubbish":0}   每 500 ms
客户端 → 设备   {"mode": 0, "gaik": 1}                        用户开盖
设备   → 客户端 {"tongk":1,"tongy":0,"tongq":1,"rubbish":0}   状态持续刷新
客户端 → 设备   {"mode": 0, "gaik": 0}                        倒计时结束或手动关盖
```
